# 📖 About the Project

This repository demonstrates how to build a modern **Azure Landing Zone** using **Terraform** by following Infrastructure as Code (IaC) and DevOps best practices.

The project focuses on creating a reusable, modular, secure, and scalable Azure foundation that can be used for real-world enterprise deployments.

- ✅ Modular Terraform Code
- ✅ Azure Landing Zone Architecture
- ✅ Infrastructure as Code (IaC)
